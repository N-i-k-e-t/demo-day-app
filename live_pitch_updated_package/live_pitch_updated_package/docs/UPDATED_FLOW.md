# Updated End-to-End Flow

1. **Join Event** — QR/link → full name + email.
2. **Startup List** — investor immediately sees all 15 startups.
3. **Choose Startup** — tap a startup to open its detail/pitch page.
4. **Submit Response** — choose exactly one: Interested, Explore More, or Not Interested.
5. **Record** — response is inserted into the authoritative database and becomes immutable.
6. **Confirmation** — investor sees “Response recorded!”.
7. **Return to List** — the selected startup is colored according to the response.
8. **Continue** — investor can choose another startup and repeat the flow.
9. **Admin** — admin sees aggregate/recorded responses and prepares a publication snapshot.
10. **Stage** — stage only changes when the admin explicitly publishes an approved snapshot.
11. **Complete** — investor can review all of their own responses after the event.
